# AEGIS — Autonomous Security for Every Transaction

AEGIS is an interactive, editorial product experience built for web3 autonomous security and wallet protection.

---

## 🛠️ Technology Stack

- **Framework**: React 18 (Vite SPA)
- **Animation & Choreography**: GSAP 3 + ScrollTrigger
- **Smooth Scroll Engine**: Lenis
- **UI Components & Motion**: Framer Motion
- **Styling & Fonts**: CSS3 (Custom Design Tokens), Google Fonts (`Anton`, `Space Grotesk`, `Plus Jakarta Sans`, `JetBrains Mono`)

---

## 🚀 Local Development Setup

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### 1. Installation
Clone the repository and install dependencies:
```bash
git clone https://github.com/MackenzieCampbelAndross/AEGIS.git
cd AEGIS
npm install
```

### 2. Run Development Server
Start the local Vite development server:
```bash
npm run dev
```

### 3. Production Build & Preview
Build the production bundle and preview it locally:
```bash
npm run build
npm run preview
```

---

## ⚡ Deploying to Vercel

1. Push your changes to the `main` branch of `https://github.com/MackenzieCampbelAndross/AEGIS`.
2. Connect your repository in the [Vercel Dashboard](https://vercel.com).
3. Vercel will automatically detect **Vite** and configure the build settings:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. Click **Deploy**.
